The files under `results/` are the primary raw outputs used in the paper for the MINEC corpus.

Important interpretation notes:
- `minec_ground_truth_v2.json` is the current corrected ground-truth file after merging manual review decisions from `data/manual_review_336_decisions.txt` (336 decisions; 331 merged as `manual_mark_txt`, 5 superseded by the 300-pair blind annotation — see `data/manual_review_336_decisions.README.md`).
- `human_verified_pairs_context.json` — per-pair context (names, attributes, source fragments, labels) for all 599 uniquely human-verified pairs (342 human-decided ∪ 300 blind, 43 overlap); fragment coverage 75.0% of pairs. Derived view — regenerate with `code/generate_human_verified_context.py`.
- Earlier consolidated artifacts (`_OBSOLETE_*`) have been moved to `experiments/legacy/results/`.
- `feedback_convergence_gt2.json` is a **cross-validation-based simulation**, not a count of live analyst feedback.
- `human_annotation_analysis.json` is the **human adjudication** artifact for the 59 GLM/GPT disagreement cases.
- `jaccard_sensitivity_gt2.json` is the fine-grained MINEC τ-sweep source used by `code/generate_jaccard_sensitivity.py`.
- `threshold_sensitivity.pdf/png` are generated by `code/generate_threshold_sensitivity.py` from `dual_threshold_sweep_gt2.json`; they are not DBP15K artifacts.

## DBP15K results

DBP15K uses three complementary result artifacts:

1. `dbp15k/results/hierarchy_feedback.json`
   - Raw fixed-L1 and adaptive-L1 cross-validation outputs.
   - Now includes `paper_reported_summary` for the final paper wording/rounding.

2. `dbp15k/results/dbp15k_glm5turbo_results.json`
   - Expanded hard-case L2 evaluation with GLM-5-Turbo.
   - Final verified summary:
     - 4,876 sampled escalated pairs
     - 4,843 valid verdicts
     - 33 format/error cases excluded
     - accuracy = 95.4%
     - precision = 96.5%
     - recall = 87.8%
     - F1 = 91.9%

3. `dbp15k/results/threshold_sensitivity.json`
   - Raw threshold-sweep curve data.
   - Now includes `provenance.paper_reported_points` matching the rounded values cited in the paper.
   - Generated by `dbp15k/code/04_threshold_sensitivity.py` and used only for the DBP15K cross-domain threshold figure, not for the MINEC Figure~\ref{fig:threshold-sensitivity} asset.

## Final paper-reported DBP15K values

Empirically replayed (strict; `dbp15k/results/dbp15k_empirical_pipeline.json`):

- Fixed L1: 78.4% accuracy / 79.3% interception / 80.5% strict pipeline / 20.7% LLM cost
- Adaptive L1: 87.8% accuracy / 92.0% interception / 88.0% strict pipeline / 8.0% LLM cost
- L2 only (GLM-5-Turbo expanded hard-case run): 95.4% on 4,843 valid / 4,876 sampled, with 33 format/error cases excluded
- Earlier formula-based estimates (81.4% / 88.3%) are superseded; the paper reports them only as the historical comparison that motivated the empirical replay.

## Why some DBP15K raw files differ slightly

The release preserves raw outputs from different evaluation steps:
- hierarchy/adaptive CV output,
- expanded hard-case L2 rerun,
- threshold-sweep curve generation.

The final paper combines them with explicit rounding and notes. The release therefore keeps both:
- raw script outputs, and
- paper-reported summaries/provenance fields.
